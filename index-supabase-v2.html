Next-phase development plan

Additional mentor recommendations identified for the next prototype phase. These are planned, not active features in this version.

AREA-LEVEL INFRASTRUCTURE MAP

Planned map layer for reported road blocks and infrastructure disruption by area. No live road-condition feed or precise vulnerable-person locations.

OFFLINE REPORT DRAFTS

Planned save-and-sync workflow for low-connectivity locations. This version currently requires an internet connection to submit to Supabase.

MULTILINGUAL INTERFACE

Planned language options, beginning with English and Hindi, with translated labels and reporting guidance.

TEXT, AUDIO AND VIDEO REPORTING

Planned accessible reporting modes. Media upload needs a separately configured, access-controlled storage service before it can be enabled.

AGGREGATE VULNERABILITY INDICATORS

Planned optional, non-identifying group-level counts only. No names, individual tracking, or sensitive personal profiles.

ACCESSIBILITY AND LOW-BANDWIDTH DESIGN

Continue improving keyboard access, readable contrast, screen-reader labels, compact pages and low-data use.
